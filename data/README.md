# Data

## Public synthetic demonstration data

`synthetic_demo.csv` is a fully synthetic episode-level dataset generated by
`src/generate_synthetic_data.py`. It is included only so that the public
repository can be executed without access to protected healthcare data.

The synthetic data:

- contain no real patient records;
- do not reproduce the private study cohort;
- do not reproduce the study's distributions or model performance;
- include repeated patients and multiple episodes so historical features and
  directed transitions can actually be exercised;
- include an `Organization` insurance category corresponding to organizational
  insurance (بیمه سازمانی).

## Private study data

The underlying study dataset is **not included**. It was derived from an
operational healthcare information system and contains sensitive healthcare
information. Raw records, patient identifiers, hashed identifiers,
patient-level train/test files, institution-specific exports, and trained
models fitted to the private dataset must remain in the authorized local
environment.

The public code does not grant permission to access or process any healthcare
dataset.
